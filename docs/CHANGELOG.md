# Changelog

All notable changes to the **E-Commerce Product Admin** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [1.2.0] - 2026-11-09

### Added
- Deployment documentation covering GitHub Pages, Vercel, and Netlify (`docs/DEPLOYMENT.md`).
- Formal API specification with cURL examples (`docs/API_REFERENCE.md`).
- Security policy and vulnerability disclosure instructions (`docs/SECURITY.md`).
- Quality assurance manual test cases checklist (`docs/TESTING.md`).
- GitHub community templates for issues and pull requests.
- Full MIT License file.

---

## [1.1.0] - 2026-11-08

### Added
- Architecture diagrams and asynchronous data flow documentation.
- Browser compatibility matrix covering modern desktop and mobile browsers.
- Performance optimization guidelines for DOM batching and event handling.
- Project roadmap detailing upcoming features.
- Contributing workflow guidelines.

---

## [1.0.0] - 2026-08-14

### Added
- Initial project structure with `index.html` and `index.js`.
- Cloud REST API synchronization using Axios and CrudCrud.
- Add product form with dynamic total price computation.
- Delete product action with instant UI list removal.
